# Awaj (আওয়াজ) — বাংলা ভয়েস অ্যাসিস্ট্যান্ট ও অটোমেশন অ্যান্ড্রয়েড ইঞ্জিন

> **একটি বাংলা-প্রথম, ভয়েস-ফার্স্ট অ্যান্ড্রয়েড অ্যাসিস্ট্যান্ট ও অটোমেশন ইঞ্জিন।**  
> এটি ব্যবহারকারীর কথা শুনে কমান্ড বোঝে, নিরাপদ কাজগুলো সরাসরি করে, ঝুঁকিপূর্ণ কাজে নিশ্চিতকরণ নেয়, এবং প্রয়োজন হলে সীমিতভাবে অন্য অ্যাপের স্ক্রিন পড়ে কাজ করে।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

### ১. তিনটি সুনির্দিষ্ট মোড (3 Modes)
1. **Safe Mode (প্লে-স্টোর সেফ)**: Android Intent, Settings API, AlarmManager, Contacts ও Media Controller এর মাধ্যমে ১০০% নিরাপদ ও পলিসি-সম্মত কাজ।
2. **Accessibility Mode (সহায়ক মোড)**: দৃষ্টি ও শারীরিক প্রতিবন্ধীদের জন্য স্ক্রিনের উপাদান পড়ে শোনানো এবং সহায়ক ভয়েস নেভিগেশন।
3. **Lab Agent Mode (ল্যাব মোড)**: পাওয়ার ইউজার এবং গবেষণার জন্য স্বায়ত্তশাসিত GUI Agent (ReAct Loop) যা স্ক্রিন বিশ্লেষণ করে কাজ সম্পন্ন করতে পারে।

### ২. শক্তিশালী বাংলা ও বাংলিশ NLU (Natural Language Understanding)
- **বাংলা সংখ্যা ও সময় রূপান্তর**: `সকাল ৮:৩০`, `রাত ৯টা`, `দুপুর ২টা`, `৫ মিনিট`, `কাল সকালে` ইত্যাদি নিখুঁতভাবে পার্স করে।
- **ডাকনাম ও কন্টাক্ট রেজোলিউশন**: `আম্মু`, `মা`, `বাবা`, `ভাইয়া`, `রাহুল`।
- **২০+ মৌলিক কমান্ড সাপোর্ট**:
  - অ্যাপ লঞ্চ (`হোয়াটসঅ্যাপ খোলো`, `ইউটিউব চালাও`, `ক্যামেরা অন করো`)
  - ফোন কল ও SMS (`মাকে কল দাও`, `রাহুলকে এসএমএস পাঠাও`)
  - হোয়াটসঅ্যাপ মেসেজ ড্রাফটিং ও সেন্ডিং
  - টর্চ / ফ্ল্যাশলাইট নিয়ন্ত্রণ (`টর্চ জ্বালাও`, `টর্চ বন্ধ করো`)
  - ভলিউম ও ব্রাইটনেস সমন্বয় (`ভলিউম ৫০% করো`, `ব্রাইটনেস কমাও`)
  - অ্যালার্ম ও টাইমার (`কাল সকাল ৭টায় অ্যালার্ম দাও`, `১০ মিনিটের টাইমার দাও`)
  - আবহাওয়া ও গুগল অনুসন্ধান
  - ব্যাটারি ও ফোনের অবস্থা যাচাই
  - মিডিয়া নিয়ন্ত্রণ (`গান পজ করো`, `পরের গান চালাও`)
  - এমার্জেন্সি বাতিল (`থামো`, `বাতিল`, `স্টপ`)

### ৩. অন্তর্নির্মিত নিরাপত্তা ও পারমিশন গেট (Safety & Security Gate)
- **আর্থিক লেনদেন ও পিন সম্পূর্ণ ব্লকড**: বিকাশ (`bKash`), নগদ (`Nagad`), রকেট (`Rocket`), সেলফিন (`CellFin`), সিটিটাচ (`Citytouch`), ব্যাংক অ্যাপ, পাসওয়ার্ড, পিন (`PIN`), এবং ওটিপি (`OTP`) যুক্ত যেকোনো কমান্ড স্বয়ংক্রিয়ভাবে ব্লক করা হয়।
- **দ্বিমুখী নিশ্চিতকরণ (Confirmation)**: কল, মেসেজ বা সংবেদনশীল কমান্ডে ভয়েস বা স্ক্রিনে "হ্যাঁ" / "না" যাচাই বাধ্যতামূলক।
- **প্রাইভেসি-ফার্স্ট অডিট লগ**: কোনো অডিও বা স্ক্রিন ডেটা ক্লাউডে পাঠানো হয় না। সব হিস্ট্রি ডিভাইসের লোকাল Room SQLite ডেটাবেজে থাকে এবং এক ট্যাপে মুছে ফেলা যায়।

### ৪. আধুনিক জেটপ্যাক কম্পোজ ইউআই (Modern Jetpack Compose UI)
- ডার্ক ও গ্লাস মরফিজম থিম (`#0B0F19`, `#131B2E`, `#6366F1`)
- অ্যানিমেটেড পালসিং গ্লোয়িং মাইক অর্ব
- ইন্টারেক্টিভ কুইক কমান্ড চিপস
- পারমিশন সেন্টার ও সেটিংস মোড সুইচার

## 🛠 প্রযুক্তি ও আর্কিটেকচার (Tech Stack)

- **Language**: Kotlin 2.0+
- **UI Framework**: Jetpack Compose, Material 3
- **Database**: Room Database (SQLite)
- **Speech Engine**: Android SpeechRecognizer (`bn-BD`), Android TextToSpeech (`bn_BD` / `bn_IN`)
- **Intelligence**: Rule-based Regex Parser + Gemini 1.5 Flash Tool Calling API
- **Services**: Foreground Voice Service, Floating Overlay Service, Accessibility Service, Notification Listener
- **Architecture**: Clean Architecture / Repository Pattern / Unidirectional Data Flow

## 🚀 কীভাবে বিল্ড করবেন (Build & Run)

1. **Android Studio**-তে প্রোজেক্টটি ওপেন করুন:
   `File -> Open -> c:\Users\joysr\Documents\awaj`
2. Gradle Sync সম্পন্ন করুন।
3. ডিভাইস বা এমুলেটরে রান করুন:
   ```bash
   ./gradlew assembleDebug
   ```
4. অ্যাপ ওপেন করে মাইক্রোফোন ও প্রয়োজনীয় পারমিশন মঞ্জুর করুন।
5. মাইক বাটনে ট্যাপ করে বাংলায় কমান্ড দিন: *"টর্চ জ্বালাও"*, *"হোয়াটসঅ্যাপ খোলো"*, *"সকাল আটটায় অ্যালার্ম দাও"*।
